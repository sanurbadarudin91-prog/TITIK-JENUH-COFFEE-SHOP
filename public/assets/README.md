# TITIK JENUH COFFEE SHOP — Aset & Media

Folder ini dipakai untuk **logo, foto, dan video** kafe.
Silakan ganti file di bawah dengan punyamu sendiri (nama file harus sama).

## File wajib

| File | Kegunaan | Ukuran disarankan |
|---|---|---|
| `logo.png` | Logo navbar + footer + admin | 512 × 512 px (persegi, PNG transparan) |
| `hero.mp4` | Video hero (proses seduh / suasana kafe) | 1080 × 1350 (4:5), < 8 MB |
| `hero-poster.jpg` | Gambar pembuka video | 1080 × 1350 px |

## Foto galeri "The Vibe"

| File | Sudut yang difoto |
|---|---|
| `vibe-indoor.jpg` | Area indoor ber-AC |
| `vibe-outdoor.jpg` | Area outdoor / merokok |
| `vibe-workspace.jpg` | Spot kerja / laptopan |
| `vibe-bar.jpg` | Coffee bar / barista |
